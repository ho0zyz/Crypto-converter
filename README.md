## 🇷🇺 Описание проекта (Russian)

Простой и быстрый консольный конвертер, который позволяет переводить традиционные (фиатные) валюты в популярные криптовалюты и обратно по актуальному рыночному курсу в реальном времени.

### 🌟 Основные возможности
* **Актуальные курсы:** Данные обновляются автоматически при каждом запуске через бесплатные API.
* **Поддержка фиата:** USD, EUR, RUB, BYN и другие.
* **Поддержка криптовалют:** Bitcoin (BTC), Ethereum (ETH), Solana (SOL), Ripple (XRP).
* **Гибкая конвертация:** Можно переводить как USD в BTC, так и SOL в EUR или RUB в BYN.

### 🛠 Инструкция по запуску
1. **Установите необходимые библиотеки** (требуется интернет):
   ```bash
   pip install -r requirements.txt
   ```
2. **Запустите скрипт**:
   ```bash
   python main.py
   ```

## 🇬🇧 Project Description (English)

A simple and fast command-line converter that allows you to convert traditional (fiat) currencies into popular cryptocurrencies and vice versa using real-time, up-to-date market rates.

### 🌟 Key Features
* **Live Exchange Rates:** Data updates automatically on every launch via free APIs.
* **Fiat Support:** USD, EUR, RUB, BYN, and more.
* **Crypto Support:** Bitcoin (BTC), Ethereum (ETH), Solana (SOL), Ripple (XRP).
* **Flexible Conversion:** Convert USD to BTC, SOL to EUR, or RUB to BYN flawlessly.

### 🛠 Installation & Running
1. **Install required dependencies** (internet connection required):
   ```bash
   pip install -r requirements.txt
   ```
2. **Run the script**:
   ```bash
   python main.py
   ```

## 📊 Используемые API / APIs Used
* [Exchange Rate API](https://exchangerate-api.com) — для курсов мировых валют / for fiat currency rates.
* [CoinGecko API](https://coingecko.com) — для актуальной стоимости криптовалют / for live cryptocurrency prices.
